# 차근차근 · 활동지 스튜디오

사회복지사를 위한 활동지 제작 도구의 첫 프론트엔드 버전입니다. 제품 요구사항은 [PRD.md](PRD.md)에 있습니다.

## 실행

Node.js 22.12 이상 또는 24를 사용합니다.

```sh
npm ci --cache /tmp/worksheet-npm-cache
npm run dev
```

## 검증

```sh
npm test
npm run build
```

## 현재 기능

- 간단 제작과 상세 제작, 읽기 수준 선택
- 세안·손 씻기·양치의 규칙 기반 초안, 다른 주제의 편집용 기본 틀
- 2쪽 미리보기, 순서 번호·O/X·따라 쓰기 선택
- 제목과 문장 직접 편집, 브라우저 localStorage에 마지막 초안 자동 저장
- 진행 안내 선택 출력, A4 인쇄 및 인쇄 창의 ‘PDF로 저장’
- 모바일 화면 대응

현재 AI API, Firebase, 구글 로그인은 연결하지 않았습니다. 계정별 저장이 아니며 같은 브라우저의 마지막 초안만 보관합니다. 새 초안을 생성하면 이전 임시 초안을 대체합니다. 자유 주제의 실제 맞춤 생성, 그림 편집, 여러 수준 동시 생성, 나머지 활동 유형과 자료 목록은 후속 구현 대상입니다.

PDF는 별도 다운로드 엔진 없이 브라우저 인쇄 창에서 저장합니다. 출력 전에 내용과 정답을 확인해주세요. 개발용 생성 규칙은 `src/generator.js`에 분리되어 있어 이후 서버 기반 AI 생성으로 교체할 수 있습니다. API 비밀키는 프론트엔드에 넣지 않습니다.
